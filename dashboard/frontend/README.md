# QHAI 工作台前端

React + TypeScript + Vite，使用 CodeMirror 编辑程序、SVG 展示电路与曲线、Three.js 展示计算输出的分子轨迹。界面与 API 在正式使用时共用一个地址。

## 开发

使用 Node.js 24 LTS。在此目录运行：

```bash
npm ci
npm run dev
```

开发服务代理 `/api` 到 `http://127.0.0.1:8787`，请先启动 Dashboard 后端。

```bash
npm run typecheck
npm test
npm run build
npm run check:dist
npx playwright install chromium
npm run test:e2e
```

提交源码修改时一并提交 `dist/`。构建生成不含时间戳的源码 SHA256 清单；`check:dist` 检查预构建资源与源码是否一致。普通使用者直接启动上级目录的 `serve.py`，无需 Node.js。字体由 npm 包提供并构建到本地，无外部字体请求。

## 交互与数据

- CPU、GPU、QPU 只展示后端声明支持的资源；刷新不会替换可选阶段的硬件选择。固定 CPU 协调阶段的旧目标已移除时，自动关联当前 CPU。
- `local_cpu` 显示为“Simulation · CPU 数值计算”。单水和自编电路默认选择 Fake SC-36 量子目标，经典模型默认选择 A100 参考 GPU；数值计算由 CPU 完成。同一套阶段目标用于运行和性能预测。
- 计算资源展示只读 Fake SC-36（6×6、36 比特、60 条最近邻无向边），有效采样吞吐 10,000 shots/s、每批提交时延 1 ms。它是未经实机标定的示例，预测只用吞吐模型，不计算布线、门深度和噪声。CPU 仅计算实际电路宽度，自编电路保持 1–12 逻辑比特，单水为 3 比特。
- 请求包含选定硬件的参数摘要；参数变化后编译状态自动失效。运行和预测结果读取各自保存的目标参数，实际执行设备来自执行记录；旧草稿与缺少参数快照的历史仍可显示。CPU 实测用时与目标硬件预测耗时分别记录。
- 后端执行的是点击运行时的程序快照；提交后仍可编辑。迟到的编译响应不能覆盖新草稿。
- 当前任务每秒查询，终态停止；连接失败重试，切换任务中止旧请求。资源每十秒更新。
- 运行与预测 ID 保留在地址栏，程序草稿按示例保存于浏览器。
- 轨迹从终态任务逐页获取真实 O/H/H 坐标、步数和时间；球棍模型不生成中间物理状态。滑块按真实记录定位，与能量曲线联动。
- 没有 WebGL 时展示坐标表；能量曲线、日志和文件下载仍可使用。

## 设计约定

浅色仪器工作台：背景 `#F3F6FA`、面板白色、正文 `#24364B`；CPU 灰蓝、GPU 蓝、QPU 琥珀色。硬件阶段关系是主要视觉表达，周边操作保持克制；状态始终有文字，颜色不是唯一信息来源。Noto Sans SC 用于界面，IBM Plex Mono 用于程序与精确数值。CSS Modules 隔离组件样式；键盘焦点可见、支持窄屏与减少动效偏好。

浏览器测试使用明确的 API fixture 校验界面状态与请求时序；真实 CPU/Ray 计算验收由 Dashboard 集成测试完成，不将 fixture 结果标记为硬件验收。
