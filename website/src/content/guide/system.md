PivotQ 是面向 **CPU、GPU 与 QPU 协同计算的量超智融合系统**。用户把程序拆分为计算组件，声明资源和数据依赖，框架在前序结果准备好后安排后续计算。CPU 负责通用计算，GPU 运行应用提供的加速计算，QPU 通过量子后端与设备适配层接入；未连接 QPU 时，也可以选择在 CPU 上运行的量子模拟器。

第一次使用，先[安装 PivotQ](./installation/)，再运行[快速上手](./quickstart/)中的完整 Python 示例。示例在本机启动 Ray，完成经典预处理、量子电路采样与经典更新。GPU 应用的资源要求和接入方式见 [GPU 与异构资源](./gpu-computing/)；在界面中操作应用，可直接跳到[启动工作台](#启动工作台)。

## 系统介绍

以水分子计算为例：CPU 根据当前原子位置准备电路输入，量子后端返回一组测量数值，CPU 上的经典模型用这些数值预测能量，程序再求力并更新原子位置。要自己编写这类程序，可以使用下方的 Python SDK；要在界面中运行已接入的水分子应用，可以启动工作台。

首页的 CPU、GPU、QPU 代码展示的是另一项流程验证：CPU 输出 `-1`，GPU（显卡）在 CUDA 上计算反余弦 `acos(-1)=π`，程序用这个角度构造电路，再向 QPU 测试后端请求结果。最后一段代码把同一验证程序作为 Ray 作业提交；测试后端返回固定数据，没有连接真实 QPU。这段验证程序、公开 Python SDK 和水分子工作台是三个不同的代码入口。

### 融合编程框架：连接组件、资源与执行

用户将程序拆分为可调用的计算组件，例如数据预处理、量子电路计算、经典模型推理和结果分析。组件通过输入与输出连接前后依赖；在支持配置的步骤中指定对应设备。框架提交任务、等待前置结果，并将结果交给后续组件。

公开 Python SDK 默认在本机线程池执行；显式选择 Ray 时，框架把任务安排到本机或集群的计算进程。独立调用可以作为任务运行，需要复用模型或设备连接的组件可以作为持有状态的服务运行。CPU 与 GPU 上的具体算法由应用组件实现，QPU 组件通过设备适配层提交量子电路、接收计算结果。仓库内的 GPU 应用使用 Ray 资源声明与 CUDA 环境；当前公开 SDK 的任务和组件接口只直接暴露 CPU 资源参数，接入细节见 [GPU 与异构资源](./gpu-computing/)。

### 性能模拟器：评估任务与硬件配置

性能模拟器需要应用提供每一步的工作量，例如 CPU/GPU 要完成多少计算、量子电路重复采样多少次，以及目标设备的计算能力和采样速度。它据此估算各步骤和整个任务需要多久，帮助用户比较不同设备配置；它不会从任意 Python 程序中自动推导这些工作量。底层 QPerfSim 与工作台支持 GPU 性能场景；公开 Python `Workload` / `Hardware` 构建器当前直接描述 CPU、QPU 与通信链路。

性能预测可以在连接真实 QPU 之前进行，但只对已有性能模型的设备组合给出耗时；其他组合会在工作台说明不能预测的原因。用户根据预测结果调整任务参数或硬件分配，再决定提交的配置。预测描述目标硬件条件下的预计性能；任务运行记录则反映实际执行后端的实测时间，两者在界面中分别展示。

### 可视化工作台：配置任务与查看结果

仓库中的工作台提供 H₂O AIMD 和量子电路示例。用户可以编辑示例代码与参数、编译并查看电路，在右侧“执行流程”中为可配置阶段选择设备；对支持的配置可以预测耗时，再提交任务。结果中心汇总运行状态、执行记录、日志和输出文件；水分子应用还提供轨迹和能量曲线。

工作台编辑器中的 `qhai.tasks` 是受控配置语法；公开 SDK 使用 `import pivotq` 编写独立 Python 程序。两种入口的代码不能直接互换。

### 各模块如何配合

一次混合计算通常沿着以下流程完成：

1. **编写应用与拆分组件**：由应用定义算法和输入输出，把经典计算、量子计算等步骤组织成完整流程。
2. **指定资源与依赖**：为可配置的步骤选择目标设备，把前一步的输出交给需要它的下一步。
3. **评估执行性能**：应用侧提供用于预测的任务描述，性能模拟器结合硬件配置估算耗时，供用户比较和调整。
4. **提交并执行任务**：融合编程框架根据用户确认的配置协调组件运行，将前序结果传给后续计算。
5. **查看结果与记录**：应用输出计算结果，工作台展示执行状态、日志与可视化内容，支持用户继续调整下一次计算。

在水分子 AIMD 示例中，这一流程依次计算量子测量数值、预测能量、求力并更新原子位置。分子模型和动力学算法由该应用提供。

## Python SDK：编写自己的程序

公开 `pivotq` Python SDK 用普通 Python 函数提交 CPU 任务，用量子后端提交电路。量子后端默认在 CPU 上模拟；连接 QPU 需要先配置对应的设备适配器（Provider）。首页 GPU 计算片段来自独立的流程验证，不是以下 SDK 示例的一步。SDK 目前已验证 Linux x86-64 和 Python 3.12；从完整仓库安装并运行：

```bash
git clone https://github.com/JanusQ/PivotQ.git
cd PivotQ
python3.12 -m venv .venv-sdk
. .venv-sdk/bin/activate
python -m pip install ./packages/framework
python packages/framework/examples/hybrid_program.py --executor ray --address local
```

这段示例在本机启动 Ray，按 CPU 构造电路、CPU 模拟量子电路、CPU 更新参数的顺序运行；不会自动使用 GPU 或连接真实 QPU。随后可阅读 [Python SDK 快速上手](./quickstart/) 和 [SDK 源码说明](https://github.com/JanusQ/PivotQ/blob/main/packages/framework/README.md)，再替换示例中的计算函数。完整公开接口见 [API 参考](./api/)。

## 启动工作台

这里是静态网站，可以阅读文档和已保存的示例，不能提交计算任务。要按教程编译电路、预测耗时和运行水分子任务，需要在本机另行启动工作台。下面的教程使用 H₂O AIMD。安装 Docker，并确认它支持 Linux x86-64 容器，然后在终端执行：

```bash
docker pull janusq/pivotq:latest
docker run --rm --init \
  --name pivotq \
  -p 127.0.0.1:8787:8787 \
  --shm-size=1g \
  -v pivotq-data:/data \
  janusq/pivotq:latest
```

保持容器运行，在同一台电脑的浏览器地址栏输入 `http://127.0.0.1:8787/`。随后按下一节的水分子 AIMD 教程操作。

## 水分子 AIMD 教程

在运行中的工作台选择 H₂O AIMD，然后按[水分子 AIMD 工作台教程](./aimd/)依次编译电路、分配硬件、预测耗时、提交任务并查看结果。

教程中的**目标配置**使用参考 CPU 与虚拟 QPU“Fake SC-36”；截图中的**实际运行**采用 CPU 数值模拟，没有连接真实 QPU。目标硬件预测与 CPU 实测用时不能作为同一硬件上的预测误差比较。教程的 `qhai.tasks` 片段是工作台编辑器解析的配置语法，不是 `pivotq` Python SDK 的导入示例。
